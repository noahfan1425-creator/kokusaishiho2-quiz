# 国際私法Ⅱ 対策練習問題

契約・不法行為（法の適用に関する通則法 7〜12条・17〜22条）の試験対策用Webアプリ（単体HTML・サーバー不要）。

## 使い方
`国際私法2_対策練習問題.html` をブラウザで開く。

## 構成
- **模試 第1回／第2回**：穴埋め20問＋記述2問＝30点・30分タイマー付
- **ランダム模試**：全問プールから毎回シャッフル出題
- **記述対策**：記述14問＋模範解答・採点キーワード
- **ドリル（契約／不法行為）**：穴埋め全問＋シャッフル
- **チェックシート**：準拠法の要点・主要判例早見

## 仕様
- 範囲：①契約／②不法行為
- 配点：30点／形式：空欄穴埋め＋記述式／時間：30分程度
- 穴埋めは自動採点（条・全角半角・別解に対応）、記述は模範解答で自己採点

※講義資料PDF等の著作物はリポジトリに含めていません。
